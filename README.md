# 📚 Meus Sites Favoritos - Agenda 12 (DS I)

Repositório criado para a atividade da **Agenda 12** da disciplina de **Desenvolvimento de Sistemas I.**

## 🚀 Sobre o Projeto
Esta página web foi desenvolvida para organizar, favoritar e disponibilizar de forma prática o acesso rápido aos meus principais sites de estudo e entretenimento.

## 🛠️ Tecnologias Utilizadas
* **HTML5**: Estruturação semântica da página e utilização de tags como `<h1>`, `<a>`, `<img />`.
* **CSS3**: Estilização visual moderna utilizando cartões (*cards*), sombras e alinhamento centralizado.
